# Hub — Plataforma modular de microapps

Plataforma centralizada de herramientas independientes (microapps) con sistema de plugins.
Esta primera versión contiene **solo el núcleo** (frontend, API, plugins, tareas, archivos, configuración).
**No incluye ninguna microapp.**

Estado: Etapa 1 (arquitectura y planificación) completada. Ver `docs/architecture.md`.
